# LUCIA — Modern Mediterranean Restaurant

> A complete restaurant website and digital menu concept created as a portfolio project.

**LUCIA** is a fictional Mediterranean restaurant concept created to explore the intersection of **restaurant branding, editorial web design, digital menus, and interactive user experiences**.

The project includes a responsive restaurant website, detailed digital menu, downloadable PDF menu, wine selection, restaurant information, and interactive booking experience.

## ✦ Live Website

**[Visit LUCIA](https://brikenacoding.github.io/lucia-restaurant/)**

## ✦ About the Project

LUCIA was designed as a premium Mediterranean restaurant concept with an emphasis on atmosphere, typography, photography, and editorial-style layouts.

The visual direction draws inspiration from:

* Natural stone and wood
* Mediterranean landscapes
* Olive groves
* Warm, earthy materials
* Contemporary fine dining
* Editorial typography

The goal was to create a digital experience that feels like a **real restaurant brand**, rather than a generic website template.

## ✦ Design Direction

The visual identity combines sophisticated typography, generous spacing, natural tones, large imagery, and editorial layouts to create a refined Mediterranean atmosphere.

The website was designed with both **desktop and mobile experiences** in mind.

## ✦ Purpose

This is a **fictional restaurant concept created exclusively as a portfolio project**.

LUCIA is not an operating restaurant, and the restaurant name, branding, menu, pricing, location, and content are created for demonstration purposes.

The project demonstrates the ability to design and develop a complete digital experience for a hospitality brand.
